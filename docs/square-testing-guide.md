# Square 广场功能测试指南 🧪

## 📋 测试前准备

### 1. 启动后端服务
```bash
cd pybackend
python main.py
```

后端服务应该运行在 `http://localhost:8000`

### 2. 启动前端服务
```bash
npm run dev:h5
```

前端服务应该运行在 `http://localhost:5173`

### 3. 确认数据库
确保 `pybackend/dreamfly.db` 存在，并且包含以下表：
- `users` - 用户表
- `minds` - 意识体表
- `user_profiles` - 用户资料表
- `thought_cells` - 思想元胞表
- `thought_likes` - 点赞表
- `thought_comments` - 评论表
- `user_follows` - 关注表

## 🐛 常见问题排查

### 问题 1: 页面一直显示"加载中..."
**可能原因**：
- 后端服务未启动
- API URL 配置错误
- 数据库连接失败

**解决方法**：
1. 检查后端服务是否运行：`http://localhost:8000/docs`
2. 检查浏览器控制台的错误信息
3. 检查 Network 标签的 API 请求状态

### 问题 2: 发布失败
**可能原因**：
- 未登录
- Token 过期
- 内容为空
- 后端验证失败

**解决方法**：
1. 检查 localStorage 中的 `auth_token`
2. 检查控制台的错误信息
3. 检查 Network 标签的请求和响应

### 问题 3: 点赞不生效
**可能原因**：
- 未登录
- API 调用失败
- 数据库错误

**解决方法**：
1. 检查控制台的错误信息
2. 检查 Network 标签的 API 请求
3. 检查后端日志
